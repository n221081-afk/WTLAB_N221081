Aim and Lab Tasks

The aim of this lab is to build a responsive digital resume website using Bootstrap and jQuery, demonstrating responsive design, grid layout, navigation, components, and interactive UI behavior.

Aim Description
  • Aim: Create a modern personal portfolio page using Bootstrap components and responsive utilities.
  • Description: Use Bootstrap layout, components, icons, form validation, JavaScript components, and jQuery to build a complete resume website.
Task List
  1. Set up Bootstrap, jQuery, and icon fonts.
  2. Build responsive navbar, hero, about, skills, projects, experience, gallery, interactive section, and contact.
  3. Use Bootstrap grid, responsive utilities, spacing, and image classes.
  4. Add cards, alerts, badges, progress bars, tables, carousel, modal, collapse, tooltip, and popover.
  5. Implement jQuery event handling and dynamic UI actions.
